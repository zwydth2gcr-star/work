# Спецификация: лендинг «Мозг бухгалтерии»

Дата: 2026-09-24
Источник идеи: `StartUp/yc-rfs/product-ideas.md`, идея №3 из 8 («Набор скиллов «Мозг бухгалтерии»»)

## Контекст

Идея №3 — обезличенный пак из 5–7 процедур (`SKILL.md`), которые бухгалтер может
подключить к Claude Code: закрытие месяца, сверка с контрагентами, проверка первички,
подготовка регулярного отчёта. Способ проверки спроса из идеи: выложить одну процедуру
бесплатно и посмотреть, спросят ли остальные.

Эта спецификация описывает не саму процедуру (`SKILL.md`), а лендинг, который эту идею
представляет и собирает первый интерес — как первый шаг перед тем, как процедуры будут
написаны.

## Цель страницы

- **Аудитория.** Главбухи и замы в компаниях покрупнее — те, кто делегирует процедуры
  сотрудникам и хочет автоматизировать рутину отдела, а не только свою собственную.
- **Главное действие посетителя.** Оставить контакт (почта/telegram) на форме — «пришлём,
  когда будет готово». Реального файла процедуры пока нет, поэтому це не скачивание, а сбор
  интереса.
- **Тон.** Сдержанно-практичный: без хайпа про ИИ, без воды. Факты, время, риски — как в
  самой идее в `product-ideas.md`.

## Структура страницы

1. **Hero.** Обещание: набор из 5–7 процедур для делегирования сотрудникам через Claude
   Code. Кнопка со скроллом к форме внизу страницы.
2. **Проблема / решение.** Боль — «слышали про агентов, но непонятно, с чего начать
   поручать их сотрудникам». Решение — обезличенный готовый пак процедур, не нужно
   придумывать самим.
3. **Список процедур.** Карточки: закрытие месяца, сверка с контрагентами, проверка
   первички, подготовка регулярного отчёта (+ 1–3 дополнительные на усмотрение при
   написании копирайта). Каждая карточка честно помечена как «в разработке» — реальных
   файлов процедур в репозитории ещё нет.
4. **Как это будет работать.** 2–3 шага после подписки: получаете `SKILL.md` → подключаете
   к Claude Code → запускаете на своей процедуре.
5. **Мини-FAQ.** Минимум три пункта:
   - Безопасно ли это для данных компании? (только обезличенные примеры, без реальных
     контрагентов и цифр — прямое требование из риска идеи №3)
   - Это готовая консультация? (нет, это процедуры для агента, не готовое решение под
     конкретную ситуацию)
   - Сколько это стоит? (пока бесплатно, этап проверки спроса)
6. **CTA.** Форма с полем контакта (почта или telegram) и кнопкой «Пришлите, когда будет
   готово». Технически — `mailto:` со предзаполненной темой письма, без сервера и
   хранения данных.

## Технический подход

- Один файл: `/Users/alesasycevnik/Work/mozg-buhgalterii/index.html`. Расположение —
  рядом с `Persona/` и `Game/` в корне репозитория `Work/`, по той же конвенции, что и
  эти проекты (см. `Persona/CLAUDE.md`): самодостаточная страница, `<style>` и `<script>`
  инлайн, без сборщика и внешних библиотек, открывается двойным кликом.
- CSS custom properties в `:root` с переопределением через
  `@media (prefers-color-scheme: dark)` — как в `Persona/index.html`, для автоматической
  тёмной темы.
- Палитра — отдельная от `Persona/index.html` (тёплый розовый акцент там — часть личного
  бренда автора, не подходит для B2B-лендинга главбухам). Здесь: нейтральный графит/серый
  фон и текст, один спокойный акцент под кнопки и ссылки.
- JS — минимальный: плавный скролл к форме по клику кнопки в hero, простая клиентская
  валидация поля email перед отправкой `mailto:`.
- Адаптивность под мобильную ширину обязательна — лендинг может расшариваться в
  мессенджерах.

## Риски и как они учтены (из product-ideas.md, идея №3)

- **Утечка данных работодателя.** На странице — только выдуманные примеры процедур,
  никаких реальных цифр, контрагентов и внутренних документов.
- **Честность контента.** Список процедур помечен как «в разработке» — страница не
  утверждает, что файлы уже готовы и доступны для скачивания.

## Вне рамок (out of scope)

- Написание реального содержимого `SKILL.md` для любой из процедур.
- Бэкенд или база данных для хранения оставленных контактов — используется `mailto:`.
- Аналитика/трекинг посетителей.
- Экспорт или упаковка страницы (`.zip` и т. п.) — этим лендинг отличается от готового
  пакета, что видно и по `alesya-site.zip` в `Persona/`, но здесь не требуется.

## Проверка перед сдачей (definition of done)

- Страница открывается напрямую в браузере (двойной клик), без сервера.
- Все ссылки и скролл работают, форма/`mailto:` открывает почтовый клиент с
  предзаполненной темой.
- Страница читаема и не ломается на мобильной ширине экрана.
- Текст вычитан на соответствие рискам: нет реальных данных, честно указано «в
  разработке» там, где процедур ещё нет, явно сказано, что это не консультация.
